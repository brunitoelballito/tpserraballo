NEXO URBAN - SITIO WEB PARA UN EMPRENDIMIENTO

ARCHIVOS DEL PROYECTO:
- index.html      -> Página de inicio
- info.html       -> Información sobre el emprendimiento
- contacto.html   -> Formulario de contacto
- style.css       -> Estilos personalizados
- script.js       -> Funcionalidades JavaScript

REQUISITOS CUMPLIDOS:
- 3 páginas HTML enlazadas.
- Navbar responsive con Bootstrap.
- Carrusel con 3 imágenes.
- Formulario de contacto.
- Validación con JavaScript.
- Mensaje de confirmación.
- Logo propio realizado con CSS.
- Estilos personalizados.
- Botón para volver arriba.
- Saludo dinámico según el horario.
- Footer en todas las páginas.
